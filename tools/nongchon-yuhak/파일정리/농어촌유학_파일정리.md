# 농어촌유학 업무 파일 정리

바탕화면을 **후임자가 첫날 열어 볼 목차**로 만드는 것이 목표입니다.
폴더 이름만 위에서 아래로 훑어도 업무 구조가 읽히도록 번호를 매겼습니다.

---

## 1. 바탕화면 구조

```
바탕화면\
├─ 농어촌유학\
│   ├─ 00_먼저읽기\      ← 후임자가 첫날 여는 곳
│   ├─ 10_법령지침\      근거는 무엇인가
│   ├─ 20_모집\          무엇을 하는가            학년도 → 학기 → 단계
│   ├─ 30_현황관리\      결과가 어디 쌓이는가     ★ 매일 여는 곳
│   ├─ 40_예산\          돈은 어떻게 도는가       회계연도
│   ├─ 50_제출자료\      밖에 무엇을 냈는가       요구받은 날짜순
│   ├─ 60_검토\          왜 그렇게 정했는가
│   ├─ 70_발표홍보\
│   ├─ 90_미분류\        정리 중 대기실
│   └─ 99_이전자료\
└─ 부서일반\             사업이 아니라 '나'에게 붙은 자료
```

**바탕화면 맨 위에는 폴더 두세 개만 둡니다.** 여기가 늘어나기 시작하면
바탕화면이 다시 어질러집니다. 사업이 여럿이면 `01_농어촌유학`, `02_○○사업`,
`09_부서일반` 처럼 번호를 붙여 부서일반을 맨 아래로 내리세요.

`30_현황관리`가 매일 여는 곳이라 위에 두고 싶겠지만, 그건 **즐겨찾기 고정**으로
해결하고 번호는 업무 흐름에 양보하는 편이 낫습니다.

### 왜 이 순서인가

| 번호 | 후임자가 갖는 질문 |
|---|---|
| 10_법령지침 | 이 사업은 무슨 근거로 하나 |
| 20_모집 | 그래서 무슨 일을 하나 |
| 30_현황관리 | 그 결과가 어디에 쌓이나 |
| 40_예산 | 돈은 어떻게 도나 |
| 50_제출자료 | 밖에는 무엇을 냈나 |
| 60_검토 | 왜 그렇게 정했나 |

## 2. 폴더마다 무엇이 들어가나

### `00_먼저읽기`

후임자가 첫날 여는 폴더. **이번 정리의 핵심입니다.**
후임자가 진짜 막히는 건 파일 위치가 아니라 *왜 그렇게 하는지* 입니다.

| 문서 | 왜 필요한가 |
|---|---|
| 업무 한 장 | 사업 개요, 근거, 규모, 전체 흐름 (아래 5장에 초안) |
| 연간 일정 | 3월에 뭘 하고 9월에 뭘 하나 (아래 6장에 뼈대) |
| 폴더 지도 | 이 문서를 넣어 두면 됩니다 |
| 연락처 | 13개 시군교육지원청 담당, 유학센터, 도청 관련 부서 |
| 쓰는 시스템 | 어떤 시스템에서 무엇을 하는지. **비밀번호는 쓰지 마세요** |

### `10_법령지침`

```
법령\          농어촌교육진흥법·시행령, 도 조례
도교육청지침\   250201_2025 시행지침.hwp, 260115_2026 시행지침.hwp
타시도참고\     전남·강원 등 사례
```

**연도로 나누지 않습니다.** 시행지침은 개정본이 나와도 옛 것을 계속 찾아봅니다.
연도 폴더에 흩으면 "2024년 기준이 뭐였지"를 찾을 때 세 폴더를 뒤져야 합니다.
한 폴더에 날짜순으로 쌓으면 개정 이력이 그대로 보입니다.

### `20_모집`

```
2026학년도\
  1학기\
    1_계획\        기본계획, 내부결재
    2_공고서식\    공고문, 신청서 서식, 안내문
    3_접수\        학교별 취합, 접수대장
    4_심사배정\    배정희망서, 심사자료, 배정결과
    5_결과통보\    통보 공문, 참가신청서
  2학기\           (같은 구조)
2025학년도\ … 2022학년도\
```

다음 학기 폴더는 지난 학기를 통째로 복사해서 만듭니다.
**확정·공식 문서만** 둡니다. 초안과 검토는 `60_검토`로.

### `30_현황관리` ★

```
전북_농어촌유학생_명단.xlsx    ★ 마스터. 이 파일만 고칩니다
전북_농어촌유학생_관리.xlsx      도구가 만든 워크북
농어촌유학_현황판.html           브라우저로 여는 화면
백업\  260301_명단.xlsx, 260401_명단.xlsx …
```

### `40_예산`

```
2026회계연도\  1_편성  2_집행  3_정산
2025회계연도\ …
```

**회계연도로만 나눕니다. 학년도가 아닙니다.** (아래 4장 참고)

### `50_제출자료`

```
2026\
  260315_교육부_실태조사\
  260420_도의회_행감_예산현황\
  260510_서울시교육청_지원금\
  260620_정보공개청구\
2025\ …
```

요구받은 날짜순으로 폴더를 팝니다. (아래 7장 참고)

### `60_검토`

```
제도개선\   지침·조례 개정 검토, 타시도 사례 조사
예산검토\   체제비 단가 시뮬레이션, 소요 추계
현황분석\   돌려본 표, 상급자 보고용 요약
질의응답\   학교·학부모 문의와 답변 근거
```

(아래 8장 참고)

### `90_미분류` / `99_이전자료`

`90_미분류` 는 정리하는 동안의 대기실입니다. 정리가 끝나면 비어 있는 것이
정상이고, 새 파일이 생겼는데 어디 둘지 모르겠으면 일단 여기 던져 둡니다.

`99_이전자료` 는 예전 담당자에게서 물려받았지만 아직 보지 않은 것.
정리된 폴더에 섞지 말고 격리해 두었다가 필요할 때 꺼냅니다.
1년째 안 열었으면 압축해서 치웁니다.

### `부서일반`

```
주간업무\     260302_주간업무.hwp 처럼 날짜만. 연말에 압축
과내안내\     행사, 공지, 회람
전산시스템\   매뉴얼, 계정 메모(비밀번호 제외), 설치 파일
복무인사\     연가, 출장, 연수
내서식\       자주 쓰는 양식, 결재 문구 — 가장 자주 열게 될 폴더
```

주간업무·과 행사 안내·전산 자료는 사업이 아니라 **'나'에게 붙은 자료**입니다.
바탕화면이 곧 목차인데 거기 주간업무가 섞이면 목차가 흐려집니다.
수명도 다릅니다 — 주간업무는 그 주가 지나면 죽고, 행사 안내는 행사가 끝나면
죽습니다. 몇 년 가는 사업 자료와 같은 서랍에 두면 사업 폴더가 금방 어질러집니다.

> **저장 안 하는 것도 정리입니다.**
> 부서 일반 자료의 대부분은 '받았으니 일단 저장'한 것입니다. 다 분류하려 들면
> 시간만 씁니다. 기준은 하나 — **이걸 다시 열어볼 일이 있나.** 없으면 지웁니다.
> 공문은 업무관리시스템에 원본이 그대로 남아 있습니다. 내 PC에 사본을 둘 이유는
> '자주 열어봐서' 하나뿐입니다.

## 3. 폴더 만드는 법

배치 파일(`.bat`)은 업무 PC로 반입이 안 되므로, 명령을 직접 붙여넣습니다.

1. 폴더를 만들 자리를 탐색기에서 엽니다 (바탕화면이면 바탕화면 폴더)
2. **탐색기 주소창에 `cmd` 를 치고 Enter** — 그 폴더에서 명령 프롬프트가 열립니다.
   경로를 칠 필요가 없습니다
3. 아래를 한 줄씩 붙여넣고 Enter

```bat
for %d in (00_먼저읽기 10_법령지침\법령 10_법령지침\도교육청지침 10_법령지침\타시도참고 30_현황관리\백업 60_검토\제도개선 60_검토\예산검토 60_검토\현황분석 60_검토\질의응답 70_발표홍보 90_미분류 99_이전자료) do md 농어촌유학\%d
```
```bat
for %y in (2022 2023 2024 2025 2026) do md 농어촌유학\20_모집\%y학년도 농어촌유학\40_예산\%y회계연도 농어촌유학\50_제출자료\%y
```
```bat
for %y in (2025 2026) do for %t in (1학기 2학기) do for %s in (1_계획 2_공고서식 3_접수 4_심사배정 5_결과통보) do md 농어촌유학\20_모집\%y학년도\%t\%s
```
```bat
for %y in (2025 2026) do for %s in (1_편성 2_집행 3_정산) do md 농어촌유학\40_예산\%y회계연도\%s
```
```bat
for %d in (주간업무 과내안내 전산시스템 복무인사 내서식) do md 부서일반\%d
```

**안 되면 손으로 만드세요.** 꼭 필요한 건 맨 위 열한 개뿐이고, 하위 폴더는
파일을 넣다가 필요해질 때 그 자리에서 만들면 됩니다.

### 탐색기에서 해 두면 편한 것

| 설정 | 어디서 |
|---|---|
| 파일 확장명 표시 | 보기 → 표시 → 파일 확장명 |
| `30_현황관리` 즐겨찾기 고정 | 폴더 우클릭 → 즐겨찾기에 고정 |
| 미리 보기 창 | 보기 → 미리 보기 창 (hwp·pdf를 안 열고 확인) |
| 자세히 보기 + 날짜순 | 보기 → 자세히, '수정한 날짜' 머리글 클릭 |

## 4. 파일 이름 짓는 법

```
YYMMDD_구분_내용.확장자

260315_공문_2026학년도 2학기 모집 계획 알림.hwp
260320_서식_참가신청서.hwp
260401_대장_2학기 접수현황.xlsx
260510_제출_서울시교육청 유학경비 지원 명단.xlsx
```

- **날짜 여섯 자리를 맨 앞에.** 이것만으로 탐색기가 시간순 정렬됩니다.
  공문 시행일 또는 받은 날
- **구분**은 공문 / 서식 / 대장 / 계획 / 제출 / 검토 / 참고 정도면 충분
- **못 쓰는 글자**: `\ / : * ? " < > |` — 날짜에 `2026/03/15` 처럼 빗금을
  쓰다가 막히는 일이 흔합니다
- **`최종`, `진짜최종`, `최종2` 금지.** 확정본에만 `_확정` 을 붙이고
  이전 것은 같은 자리에 `_이전` 폴더를 만들어 내립니다
- **파일 이름에 학생 이름을 넣지 마세요.** 개인정보입니다

## 5. 학년도와 회계연도는 다릅니다

|  | 기간 |
|---|---|
| 유학 업무 | **학년도** — 3월 ~ 다음해 2월 |
| 예산 | **회계연도** — 1월 ~ 12월 |

2026학년도 2학기(9월~2월) 체제비는

- 9~12월분 → **2026회계연도**
- 1~2월분 → **2027회계연도**

로 갈립니다. **한 학기 예산이 두 회계연도에 걸칩니다.**
그래서 예산 서류를 학년도 폴더에 넣으면 결산 때 반드시 못 찾습니다.

## 6. 제출자료를 왜 분야별로 흩지 않나

**찾는 방식이 다릅니다.** 제출자료는 '무엇에 관한 자료냐'가 아니라
**'언제 누구에게 냈냐'**로 기억됩니다. 감사·행감 때 "작년에 뭐 냈지"로 찾지,
"예산 관련 제출자료"로 찾지 않습니다.

**묶음이 찢어집니다.** 제출 한 건이 여러 분야에 걸칩니다. 행정사무감사
요구자료 하나에 예산·현황·법령 근거가 다 들어갑니다. 분야별로 흩으면 그 묶음이
찢어져 "그때 낸 자료 그대로" 재활용을 못 합니다.

**제출은 그 자체가 하나의 사건입니다.** 요구 공문 → 작성 → 검토 → 발송 공문이
한 세트로 남아야 합니다.

> **분야로도 찾고 싶으면** 폴더 이름에 분야 낱말을 넣으세요 —
> `260420_도의회_행감_예산현황`. 탐색기 검색창에 '예산'만 쳐도 잡힙니다.
> 바로 가기를 만들어 두는 것보다 손이 덜 갑니다.

## 7. 검토자료를 왜 따로 두나

**섞이면 판단이 늘어납니다.** 확정 문서와 초안이 한 폴더에 있으면 파일을 열
때마다 "이게 확정본인가"를 판단해야 합니다. 물리적으로 갈라 두면 그 판단이
없어집니다 — `20_모집` 안은 전부 확정·공식 문서입니다.

**후임자에게는 여기가 더 중요합니다.** "이 학교는 왜 뺐지", "이 숫자는 왜
이렇게 세지" 같은 걸 물어볼 텐데, 그때 답이 되는 게 검토 과정입니다.
결과물만 남기고 과정을 버리면 후임자는 처음부터 다시 고민하게 됩니다.

검토가 확정되어 공문이 나가면 **결과물은 해당 업무 폴더로 옮기고, 검토 과정은
`60_검토` 에 남깁니다.**

## 8. 흩어진 파일 정리하는 순서

핵심은 **분류하다가 멈추지 않는 것**입니다. "이건 어디 넣지?" 하고 멈추는
순간 정리가 끝납니다. 그래서 `90_미분류` 가 있습니다.

**1단계 — 일단 몽땅 쓸어 담기 (10분)**
바탕화면에 흩어진 업무 파일을 전부 `90_미분류` 로 옮깁니다. 보지 말고,
고민하지 말고, 그냥 옮기세요. 바탕화면이 깨끗해지는 것만으로 절반은 끝난 겁니다.

**2단계 — 쉬운 것부터 꺼내기 (30분)**
`90_미분류` 를 열고 **보기 → 자세히**, **이름순** 정렬. 비슷한 이름끼리 붙어
있어서 `Ctrl` 로 여러 개를 골라 한 번에 옮길 수 있습니다.

- 명단 파일들 → 최신본 하나만 `30_현황관리`, 나머지는 전부 `백업\`
- hwp 공문 → 이름에 연도가 있으면 그 학년도 폴더로
- 예산·정산 엑셀 → `40_예산` 의 **회계연도** 폴더로
- 법령·지침 → `10_법령지침`

**3단계 — 애매한 것**

판단 기준은 하나입니다 — **"나중에 이걸 왜 찾게 될까?"**

| 이럴 때 | 여기로 |
|---|---|
| 어느 학기인지 모르겠다 | 파일 **수정한 날짜**를 보세요. 3~5월이면 그해 1학기, 9~11월이면 2학기 |

**4단계 — 이름 고치기는 나중에**
옛 파일 이름을 전부 고치려 하지 마세요. **앞으로 만드는 파일부터** 규칙을 쓰고,

## 9. 명단 파일 다루는 법

> **고치는 파일은 언제나 하나입니다.**
> `30_현황관리\전북_농어촌유학생_명단.xlsx`

`명단_수정본.xlsx`, `명단_최종.xlsx` 처럼 사본이 늘어나기 시작하면 어느 것이
진짜인지 모르게 되고, **그 순간부터 숫자를 믿을 수 없습니다.**

스냅샷이 필요하면 `백업\` 에 날짜를 붙여 던져 넣습니다.

```
백업\260301_명단.xlsx
백업\260401_명단.xlsx
```

뜨는 시점: **접수 마감 직후 / 배정 확정 직후 / 발표 자료 낸 직후**

관리 워크북과 현황판은 **명단만 있으면 언제든 다시 만들 수 있습니다.**
사본으로 치지 않아도 되고, 지워도 됩니다.
