농어촌유학 업무 폴더 — 읽어보기
====================================================================
이 폴더를 물려받은 분이 가장 먼저 볼 문서입니다.
새 담당자가 오면 이 파일부터 읽게 해 주세요.


1. 어디에 무엇이 있나
--------------------------------------------------------------------

00_미분류        아직 자리를 못 정한 파일. 늘 비어 있는 것이 정상입니다.
                 새 파일이 생겼는데 어디 둘지 모르겠으면 일단 여기.

10_현황관리      매일 여는 곳.
                 - 전북_농어촌유학생_명단.xlsx   ★ 마스터. 이것만 고칩니다
                 - 전북_농어촌유학생_관리.xlsx     도구가 만든 것
                 - 농어촌유학_현황판.html          브라우저로 열어 씁니다
                 - 백업\                          날짜별 스냅샷

20_법령지침      연도로 나누지 않습니다. 한 폴더에 날짜순으로 쌓으면
                 개정 이력이 그대로 보입니다.
                 법령 / 도교육청지침 / 타시도참고

30_모집          학년도 -> 학기 -> 단계.
                 1_계획 2_공고서식 3_접수 4_심사배정 5_결과통보
                 다음 학기 폴더는 지난 학기를 복사해서 만드세요.

40_예산          회계연도(1~12월)로 나눕니다. 학년도가 아닙니다.
                 1_편성 2_집행 3_정산

50_제출자료      요구받은 날짜순. 폴더 이름은
                 260510_서울시교육청_지원금  형식으로 짓습니다.

60_발표홍보      보도자료, 발표자료 PDF, 사진

90_이전담당자    물려받았지만 아직 안 본 것. 정리된 폴더에 섞지 말고
                 여기 격리해 두었다가 필요할 때 꺼냅니다.


2. 파일 이름 짓는 법
--------------------------------------------------------------------

    YYMMDD_구분_내용.확장자

    260315_공문_2026학년도 2학기 모집 계획 알림.hwp
    260320_서식_참가신청서.hwp
    260401_대장_2학기 접수현황.xlsx
    260510_제출_서울시교육청 유학경비 지원 명단.xlsx

  - 날짜 여섯 자리를 맨 앞에. 이것만으로 탐색기가 시간순 정렬됩니다.
  - 날짜는 공문 시행일, 또는 받은 날.
  - 구분은 공문 / 서식 / 대장 / 계획 / 제출 / 참고 정도면 충분합니다.

  쓰면 안 되는 글자:  \  /  :  *  ?  "  <  >  |
  날짜에 2026/03/15 처럼 빗금을 쓰다가 막히는 일이 흔합니다.

  '최종', '진짜최종', '최종2' 는 쓰지 마세요.
  확정본에만 _확정 을 붙이고, 이전 것은 같은 자리에 _이전 폴더를 만들어
  내려 둡니다.

  파일 이름에 학생 이름을 넣지 마세요. 개인정보입니다.


3. 명단 파일 다루는 법 (가장 중요)
--------------------------------------------------------------------

  고치는 파일은 언제나 하나입니다.

      10_현황관리\전북_농어촌유학생_명단.xlsx

  명단_수정본.xlsx, 명단_최종.xlsx 처럼 사본이 늘어나기 시작하면
  어느 것이 진짜인지 모르게 되고, 그 순간부터 숫자를 믿을 수 없습니다.

  스냅샷이 필요하면 백업\ 폴더에 날짜를 붙여 던져 넣습니다.

      백업\260301_명단.xlsx
      백업\260401_명단.xlsx

  뜨는 시점: 모집 접수 마감 직후, 배정 확정 직후, 발표 자료 낸 직후.

  관리 워크북(전북_농어촌유학생_관리.xlsx)과 현황판(html)은
  명단만 있으면 언제든 다시 만들 수 있습니다. 사본으로 치지 않아도 되고,
  지워도 됩니다.


4. 학년도와 회계연도는 다릅니다
--------------------------------------------------------------------

  유학 업무   학년도   3월 ~ 다음해 2월
  예산        회계연도  1월 ~ 12월

  2026학년도 2학기(9월~2월) 체제비는
    9~12월분 -> 2026회계연도
    1~2월분  -> 2027회계연도
  로 갈립니다. 한 학기 예산이 두 회계연도에 걸칩니다.

  그래서 예산 서류를 학년도 폴더에 넣으면 결산 때 반드시 못 찾습니다.
  40_예산 은 회계연도로만 나눕니다.


5. 탐색기에서 해 두면 편한 것
--------------------------------------------------------------------

  파일 확장명 표시 켜기
      보기 -> 표시 -> 파일 확장명

  10_현황관리 를 즐겨찾기에 고정
      폴더에 오른쪽 클릭 -> 즐겨찾기에 고정

  미리 보기 창 켜기
      보기 -> 미리 보기 창
      hwp, pdf 를 열지 않고 내용을 확인할 수 있습니다.

  자세히 보기 + 수정한 날짜순 정렬
      보기 -> 자세히, 그다음 '수정한 날짜' 머리글을 클릭
      정리할 때 가장 많이 쓰게 됩니다.


6. 한 해가 끝나면
--------------------------------------------------------------------

  - 30_모집 에 다음 학년도 폴더를 만듭니다(지난 학년도를 복사).
  - 40_예산 에 다음 회계연도 폴더를 만듭니다.
  - 50_제출자료 에 다음 연도 폴더를 만듭니다.
  - 90_이전담당자 를 1년째 안 열었으면 압축해서 치웁니다.
