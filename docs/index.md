# 개인정보 처리방침

**앱 이름**: 출석부 (choolsukbu)
**최종 수정일**: 2026년 10월 6일

## 요약

이 앱은 **개발자에게 어떤 정보도 보내지 않습니다.** 입력하신 내용은 기기 안에 저장되고,
사용자가 원하면 **사용자 본인의 iCloud**로만 기기 간에 맞춰집니다. 개발자를 포함한 누구도
열람할 수 없습니다.

## 앱이 저장하는 정보

앱을 쓰면서 직접 입력하시는 다음 항목이 기기 내부 데이터베이스에 저장됩니다.

| 항목 | 예 |
|---|---|
| 원생 이름 | 김민준 |
| 학년 | 중2 |
| 수업 요일과 시간 | 월·수·금 16:00–18:00 |
| 월 수강료 (선택) | 350,000 |
| 출결 기록 | 날짜, 시각, 출석·예외·결석 |
| 보충 수업 기록 | 결석일, 보충 예정일, 완료 여부 |
| 미취학 아동 여부 (선택) | 교육비 공제 자료용 표시 |
| 수납 기록 | 받은 날, 금액, 수입 구분(수강료·교재대 등), 결제수단, 현금영수증 발급 여부, 메모 |
| 학원 정보 (선택) | 상호, 대표자, 사업자등록번호, 전화번호, 소재지, 교육 내용 |
| 운영 설정 (선택) | 수강료 기준표, 기본 수업 시간 |

주민등록번호, 주소, 보호자 연락처, 카드 번호는 받지도 저장하지도 않습니다. 신고 자료와
교육비 납입 증명서에 필요한 주민등록번호·주소 칸은 비워 둔 채로 내보내며, 사용자가 직접
채웁니다. 증명서를 뽑을 때 적는 신청인 이름도 저장하지 않습니다.

## 저장 위치

기기 내부의 앱 전용 저장 공간(SQLite 파일)입니다. **개발자가 운영하는 서버는 없고,
이 앱이 보내는 곳도 없습니다.**

### 기기 간 동기화 (iCloud)

같은 Apple 계정으로 로그인한 기기끼리 기록을 맞추기 위해, 위 정보를 담은 파일을
**사용자 본인의 iCloud Drive**(이 앱 전용 폴더)에 저장하고 읽어 옵니다. 이것이 이 앱의
유일한 네트워크 사용입니다.

- 파일은 사용자의 iCloud 계정 안에만 있고 Apple의 iCloud 약관과 보안이 적용됩니다.
  개발자는 접근할 수 없습니다.
- iCloud에 로그인하지 않았거나 iCloud Drive를 꺼 두면 동기화되지 않으며, 앱의 나머지
  기능은 그대로 씁니다.
- 동기화를 원하지 않으면 iOS 설정 → Apple 계정 → iCloud → iCloud Drive에서 이 앱을
  끄면 됩니다. 이미 올라간 파일은 iCloud Drive의 '출석부' 폴더에서 직접 지울 수 있습니다.

## 제3자 제공

없습니다. 광고, 분석 도구, 추적 기술을 일절 사용하지 않습니다.

## 사용자가 직접 내보내는 경우

앱의 **백업·내보내기** 기능으로 기록을 JSON·CSV 파일로, 교육비 납입 증명서를 인쇄물이나
PDF로 내보낼 수 있습니다. 이때 파일을 어디에
저장하거나 누구에게 보낼지는 전적으로 사용자가 결정하며, 앱은 그 과정에 개입하지
않고 어디로 갔는지도 알지 못합니다.

## 보관 기간과 삭제

데이터는 사용자가 지울 때까지 기기에 남습니다.

- 개별 원생 삭제: 앱의 [원생] 탭에서 원생을 선택해 삭제하면 그 원생의 출결·보충
  기록도 함께 지워집니다. 수납 기록은 세금 신고 근거라 남습니다. 지우기 전에 수납
  화면에서 그 원생의 기록을 한 건씩 지울 수 있습니다.
- 전체 삭제: 기기에서 앱을 삭제하면 저장된 데이터가 모두 사라집니다.

**두 경우 모두 복구할 수 없습니다.** 필요한 기록은 미리 백업해 두시기 바랍니다.

## 아동의 개인정보

이 앱은 학원 운영자가 원생 정보를 관리하기 위한 도구이며, 아동이 직접 사용하도록
만들어지지 않았습니다. 입력되는 원생 정보는 앱 사용자(운영자)가 관리 목적으로
직접 기입하는 것이며, 앱은 이를 외부로 보내지 않습니다.

입력하신 정보에 미성년자의 개인정보가 포함되는 경우, 그 수집과 보관에 대한 법적
책임은 앱 사용자에게 있습니다. 관련 법령에 따른 동의 절차를 갖추시기 바랍니다.

## 권한

이 앱은 카메라, 위치, 연락처, 마이크 등 어떤 기기 권한도 요청하지 않습니다. iCloud
동기화는 이 앱 전용 iCloud Drive 폴더만 사용하며, 다른 파일에는 접근하지 않습니다.
백업 파일을 내보낼 때는 시스템 공유 시트가, 증명서를 뽑을 때는 시스템 인쇄 화면이 열립니다.
생체 인증(Face ID·Touch ID)은 앱 잠금을 켠 경우에만 iOS에 요청하며, 생체 정보 자체는 앱이
받지 않습니다.
