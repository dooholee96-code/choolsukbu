# 다음 작업 (한도 재설정 후)

사용자가 파일 둘을 주고 "재설정 이후에 작업해 달라"고 했다. 순서대로 한다.

1. ~~서울시교육청 지원기준 파악~~ **끝. 아래가 확정된 기준이다.**

   출처: 담당자가 준 PDF ('26. 3. 1. 기준). 같은 PDF의 현황표·시군별 숫자는
   이전 자료라 쓰지 않는다 — 지원기준 표만 유효하다.

   | | 가족체류형 | 유학센터형 |
   |---|---|---|
   | 지원대상 | 초1 ~ 중2 | 초1 ~ 중2 |
   | 지원기간 | 최대 1년 | 최대 1년 |
   | 최초~6개월 | 가구당 1명 30 / 2명 40 / 3명 50 / 4명↑ 60만원 | 1명당 30만원 |
   | 7개월~1년 | 가구당 1명 20 / 2명 30 / 3명 40 / 4명↑ 50만원 | 1명당 20만원 |

   **앞서 추정했던 '6학기 이내' 규칙은 틀렸다.** 워크북 `서울원적_제출용` 시트의
   ○/× 수식과 `설정` 시트의 서울 관련 칸(C20·C21·C22)을 고쳐야 한다.

   고칠 때 지켜야 할 것 다섯:
   - 기간은 6학기가 아니라 **1년(2학기)**
   - **6개월을 경계로 단가가 깎인다.** 3월 1일 시작이면 1학기가 최초 6개월,
     2학기가 7~12개월로 학기와 맞아떨어진다
   - **중3은 대상이 아니다** (전북교육청은 초1~중3, 서울은 초1~중2)
   - **홈스테이형은 서울 지원 대상에 없다**
   - 가족체류형은 **가구당** 유학생 수로 차등 — 워크북의 가구ID로 묶어 센다

2. **제작 중 파일을 우리 유학생관리 파일과 대조**
   - 사용자 메모: "2학기 1차모집까지만 데이터 채웠음"
   - 기준: 원 지역이 서울인 학생. 워크북 `서울원적` · `서울원적_제출용` 시트와 맞춰 본다
   - 어긋나면 어느 쪽이 맞는지, 왜 갈렸는지까지 짚을 것

3. **서울시교육청 명단 서식을 새로 받아 채우기**
   - 1·2번을 끝낸 뒤에 한다. 서식은 그때 다시 준다고 했다
